P	18. Data Binding / Exact Context Rules
P	Project / Topic / Work Item / Thread 必須是 exact ref；不得用 stale context 或跨 Project fallback。
P	Assigned AI Set / provider capability assignment 是 shared Router-owned read-only snapshot；頁面不得手動選 provider/model。
P	Conversation branch 僅為同 Work Item 下的 thread relation，絕不是新的 production Topic。
P	Human Decision 必須保存 target ref / decision / reason / evidence refs；Assistant Structured Decision 只能重述，不可 self-approve。
P	CandidateVersion 是 immutable；返回修改必須保留舊 Candidate，後續建立新 Candidate / Version。
P	Naming / filename / artifact identity 由 ACPOS_SYSTEM 掌權；CORE 只提供 upstream refs。
P	Canonical Script 必須綁 exact Project / Topic / Blueprint / Topic Scope / Canon / DNA / source candidate lineage。
