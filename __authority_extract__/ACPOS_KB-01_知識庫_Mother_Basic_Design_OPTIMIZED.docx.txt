P	Real Execution → ACPOSExperienceRecord → Outcome Completeness → Replay exact lineage → Compare Attempt/Version → Root Cause / Pattern → Create Learning Candidate → Governed review outside KB or create Knowledge Draft → Human Knowledge Review。
