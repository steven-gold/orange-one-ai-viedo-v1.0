P	1. Requirement / Problem Definition
P	DB-01 是 ACPOS canonical data model、exact version lineage、relationships、traceability、schema/migration history、integrity findings 與 audit 的管理／Debug Viewer。
P	核心不是 CRUD，而是「看清楚 exact entity、version、reference、checksum 與 lineage」；任何 production mutation 由 Domain Service 或 System Lifecycle / Change Management 處理。
P	Formal execution 嚴禁 latest/current/default、filename guessing、silent repair。Broken/orphan/mismatch 必須成為 explicit integrity finding。
P	資料顯示 Real Data Only；沒有 Current business value 時顯示「—」，不得以假 table count、row count、migration status、checksum 或 health 填充畫面。
