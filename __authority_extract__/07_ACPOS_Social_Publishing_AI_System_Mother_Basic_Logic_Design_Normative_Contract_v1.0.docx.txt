P	1. Purpose / Scope / Out-of-Scope
P	1.1 Purpose
P	把使用者的貼文需求／Master Message 轉成可治理的 Canonical Content，再衍生為平台原生 Variant，而不是四平台盲目複製同文。
P	確保 AI 只產生 RAW_AI_DRAFT_PREVIEW；人工採用、修改、儲存與治理決策後才形成可發布 Candidate。
P	讓 Release/Asset/Approved Content 以 exact version reference 綁入 Media Binding；不在社群發布域建立第二套素材庫。
P	把 Target、Account、Platform Capability、Policy、Approval、Schedule、Rights、Classification 與 Idempotency 變成 effect-time Publish Hard Gate。
P	把 Publish Request accepted 與 external POSTED 嚴格分離；只有驗證過的 Callback/Poll + ExternalPostRef 才能形成 POSTED_CONFIRMED。
P	把 Metrics / Interaction / Attribution 轉成可追溯 Experience；Experience 只能形成 Recommendation Candidate，不能自動改發布政策或內容 Canon。
