P	6.1 UI Visual Candidate · A · AUTO Topic Review
P	A · AUTO Topic Review
P	AUTO 主畫面：左側只負責 Topic-scoped queue 與 AUTO progress；中央維持 exact output viewer；右側只顯示 System/AI scorecard。Top Context 全部 read-only。
P	6.2 UI Visual Candidate · B · MANUAL Single Review
P	B · MANUAL Single Review
P	MANUAL 模式：Human 一次選一個 QA task；Start Review 只在 NOT_STARTED + QA-01-GATE-START PASS 時可用；Scorecard 仍禁止人工打分。
P	6.3 UI Visual Candidate · C · Finding + Governed Manual Review
P	C · Finding + Governed Manual Review
P	Finding + Manual Review：Finding 可以建立；Manual Review 只在 governed ManualReviewCase required/open 時顯示，而且只有「修改 / 通過」兩個 function，不能變成空白人工評分表。
P	6.4 UI Visual Candidate · D · Recheck Before / After
P	D · Recheck Before / After
P	Recheck：只有原 failed exact version + verified NEW exact version 都存在時才 50/50；否則不渲染空 B pane。QA 不直接修改 upstream output。
P	6.5 UI Visual Candidate · E · QA Gate / Release Candidate
P	E · QA Gate / Release Candidate
P	Release Candidate：需 QA PASS、Finding closed、Manual Review closed、Rights/Policy/Channel scope 全部正確；QA 只建立 ReleasePackage Candidate，不包含 approveRelease / Publish。
