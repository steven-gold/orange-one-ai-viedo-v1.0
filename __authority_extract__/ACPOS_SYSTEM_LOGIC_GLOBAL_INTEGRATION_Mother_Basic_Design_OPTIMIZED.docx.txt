P	13. Construction / Verification Order

P	4. 驗證五大生產鏈 exact-version handoff 與 correction round-trip。
P	5. 驗證 AIAPI router / queue / provider adapter / normalized result lineage。
P	6. 驗證 KB / INFO / Strategy / DEV / SOC 對 shared acquisition 的 domain-specific binding。
P	7. 跑全站 permission-denied / version-conflict / missing-authority / provider-failure / queue-failure / stale-data negative tests。
P	8. 最後才做 Production deployment / remote browser / external provider E2E；不得由文件或本機測試推定。
